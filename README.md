# java-convenience-store-precourse

## 기능 목록

### 입출력
- [x] 상품 목록을 파일 입출력으로 불러온다
- [x] 행사 목록을 파일 입출력으로 불러온다
- [ ] 구매할 상품과 수량을 입력 받는다
  - `[상품명-수량],[상품명-수량]`
- [ ] 프로모션 적용 가능 상품에 대해 수량을 적게 가져온 경우 그 수량만큼 추가 여부를 입력받는다
  - Y(수량 추가) or N(수량 미추가)
- [ ] 프로모션 재고가 부족한 경우 일부 수량에 대해 정가로 결제할지 여부를 입력받는다
  - Y(정가 결제) or N(해당 수량 제외)
- [ ] 멤버십 할인 적용 여부를 입력받는다
  - Y(멤버십 할인 적용) or N(멤버십 할인 미적용)
- [ ] 추가 구매 여부를 입력받는다
  - Y(추가 구매) or N(구매 종료)
- [ ] 환영 인사와 상품명, 가격, 프로모션 이름, 재고를 출력한다
  - 재고가 없다면 `재고 없음` 출력
- [ ] 프로모션 적용 가능 상품에 대해 수량을 적게 가져온 경우 혜택에 대한 안내 메시지를 출력한다
  - `현재 {상품명}은(는) 1개를 무료로 더 받을 수 있습니다. 추가하시겠습니까? (Y/N)`
- [ ] 프로모션 재고가 부족한 경우 일부 수량에 대해 정가로 결제할지 여부에 대한 안내 메시지를 출력한다
  - `현재 {상품명}{수량}개는 프로모션 할인이 적용되지 않습니다. 그래도 구매하시겠습니까? (Y/N)`
- [ ] 멤버십 할인 적용 여부를 확인하기 위한 안내 문구를 출력한다
  - `멤버십 할인을 받으시겠습니까? (Y/N)`
- [ ] 영수증을 출력한다
  - 구매 상품 내역: 구매한 상품명, 수량, 가격
  - 증정 상품 내역: 무료로 제공된 증정 상품의 목록
  - 금액 정보: 총구매액, 행사할인, 멤버십할인, 최종 결제 금액
- [ ] 추가 구매 여부를 확인하기 위한 안내 문구를 출력한다
  - `감사합니다. 구매하고 싶은 다른 상품이 있나요? (Y/N)`

### Application
- [ ] 상품을 저장한다
- [ ] 할인을 저장한다
- [ ] 주문을 받는다
- [ ] 프로모션과 멤버십 할인을 진행한다
- [ ] 구매를 완료한다
- [ ] 추가 구매를 진행한다
- [ ] 영수증 출력 후 추가 구매 or 종료를 진행한다

### Domain
- [ ] 상품 재고를 저장한다
  - 일반 상품 재고를 저장한다
  - 할인 상품 재고를 저장한다
- [ ] 상품의 가격과 수량을 기반으로 최종 결제 금액을 계산한다
  - 총구매액: (상품별 가격 * 상품별 수량) 총합
  - 최종 결제 금액: 총구매액 - 프로모션 금액 - 멤버십 할인 금액
- [ ] 재고 수량을 고려해 결제 가능 여부를 확인한다
- [ ] 상품을 구매하면 구매 수량만을 재고에서 차감한다
- [ ] 재고 정보를 제공한다
- [ ] 구매 날짜가 프로모션 기간 내에 포함된 경우 프로모션 할인을 적용한다
- [ ] 프로모션은 Buy N Get 1 Free(N + 1) 형태로 진행한다
- [ ] 프로모션 혜택은 프로모션 재고 내에서만 적용 가능하다
- [ ] 프로모션 기간이라면 프로모션 재고를 우선 차감한다
- [ ] 프로모션 재고가 부족하면 일반 재고를 사용한다
- [ ] 프로모션 적용 가능한 상품에 대해 수량을 적게 가져오면 필요한 추가 수량을 알려준다
- [ ] 프로모션 재고가 부족한 경우 일부 수량을 정가로(일반 상품 취급) 결제함을 알려준다
- [ ] 멤버십 할인은 프로모션 미적용 금액의 30%를 할인해준다
  - (총구매액 - 프로모션 금액) * 0.3 = 멤버십 할인 금액
  - 멤버십 할인의 최대 한도는 8,000원
